# 01_Projekt_GPT_Test

Eine kleine, lokale Web-App für Aufgaben und Projekt-Organisation.

## Starten

Öffne einfach die Datei `index.html` im Browser.

## Funktionen

- Aufgabe hinzufügen
- Aufgabe als erledigt markieren
- Aufgabe löschen
- Filter nach Alle / Offen / Erledigt
- Dunkelmodus
- Speicherung im Browser über `localStorage`

## Projektstruktur

- `index.html` – App-Struktur
- `styles.css` – Styling
- `script.js` – Interaktive Logik
